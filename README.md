RainyDays is an online store for outdoor jackets and clothing. The project started as my Cross Course Project and was later developed further with JavaScript functionality for the JavaScript 1 course.

## Description

RainyDays is a responsive e-commerce website built with HTML, CSS, and JavaScript. The site allows users to browse products, view individual product details, filter products, add items to a cart, and complete a basic checkout flow. The project focuses on creating a clear and user-friendly shopping experience while also working with dynamic product data, localStorage, and responsive design.

## Getting Started

### Installing

1. Clone the repo:

```bash
git clone https://github.com/SondreKuven/html-css-sondrekuven
```

2. Install the dependencies:

```
npm install
```

### Running

To run the app, run the following commands:

```bash
npm run start
```
